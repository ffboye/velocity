Maps now live inside each saved journey. Open Journeys, choose a journey and see its actual street map under Route, with start/finish markers and zoom controls. The separate Map tab is removed.

Offline maps are managed in Settings. A short explanation and expandable guide show how to select an area, download over Wi-Fi and use saved streets automatically in journey routes. Existing downloads stay available, including when new downloads are switched off. Pausing, resuming and deleting downloads remain available.

Navigation has gentler transitions, more room for tab labels and a fixed Done button in journey details. If street maps fail to load, the recorded route remains visible as an outline.
