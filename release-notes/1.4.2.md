Saved journeys now receive the same validation as imported backups. Unreadable storage is preserved and recording stays disabled instead of treating it as an empty history. Invalid saves leave the previous journey file intact.

Recording avoids copying the full route every second when it has not changed.

Android recording, storage and map tests now run on pull requests and before releases. A separate process-kill test verifies background checkpoints recover exactly once without resuming recording or altering existing journeys.
